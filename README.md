# EasyMec 4.0

## Descrizione del progetto

EasyMec 4.0 è un progetto sviluppato per la materia GPOI (Gestione Progetto e Organizzazione d'Impresa).

L'idea nasce dall'esigenza di migliorare la comunicazione tra gli operatori e i vari reparti aziendali durante i fermi macchina.

## Come funziona

Quando una pressa si ferma, il sistema mostra una segnalazione sul monitor dell'operatore.

L'operatore identifica il problema e, tramite un semplice pulsante, invia una richiesta al reparto competente: manutenzione meccanica, manutenzione elettrica, attrezzaggio oppure qualità.

Il personale interessato riceve la segnalazione e può prendere in carico l'intervento.

Al termine, il sistema permette di registrare il problema riscontrato, la soluzione adottata e il tempo di fermo.

## Obiettivi

L'obiettivo principale è ridurre i tempi persi durante un fermo macchina, rendendo la comunicazione più veloce e organizzata.

Il sistema è pensato per essere semplice da utilizzare anche da parte di operatori con poche conoscenze informatiche.

## Sviluppo del progetto

Il progetto prende in considerazione, come esempio, le presse 410, 502 e 503.

La documentazione comprende l'analisi dei requisiti, 60 casi d'uso, diagrammi UML, user stories e analisi SWOT.

Attualmente EasyMec 4.0 è in fase di progettazione. L'obiettivo successivo sarà realizzare una prima versione funzionante dell'applicazione web.
